## Release Title & Release Notes Style

When releasing a new version, always write the release title and release notes in a modern, polished, and engaging style.

### Rules
- NEVER reuse the same emoji for every release title.
- Use a different, relevant emoji for each release based on the version's main theme.
- Avoid repetitive titles such as `🚀 VLC RPC v6.1`, `🚀 VLC RPC v6.2`, `🚀 VLC RPC v6.3`.
- Release titles should feel unique, modern, and product-focused.
- Use varied emojis such as ✨, ⚡, 🧠, 🎨, 🔥, 🛠️, 🎯, 💎, 🌙, 📡, 🔄, 🧩, 🛡️, 📊, 🎬, etc., choosing one that actually fits the release.
- Keep release titles concise and memorable.
- Release notes should be clean, modern, and easy to scan.
- Use varied emojis for sections instead of repeating the same emoji throughout every release.
- Highlight major features, improvements, fixes, performance changes, and important technical changes clearly.
- Do not overuse emojis. They should improve readability and personality, not make the release notes look childish or cluttered.
- Do not use generic filler such as "Various bug fixes and improvements" when specific details are available.
- Never fabricate features, fixes, or changes that were not actually implemented.

### Preferred Format

# <Unique Emoji> VLC RPC vX.X.X — <Release Theme>

A short 1–2 sentence description explaining what makes this release important.

## ✨ Highlights
- Major feature or improvement
- Major feature or improvement

## ⚡ Improvements
- Performance improvements
- UX improvements
- Reliability improvements

## 🛠️ Fixes
- Specific bug fix
- Specific bug fix

## 🔧 Technical
- Important internal/architecture changes

## 📦 Upgrade
Brief upgrade/migration notes if necessary.

Release titles and notes should feel like a **modern professional software product**, not a generic automatically generated changelog.
